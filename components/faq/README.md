# FAQ Component ("Visitor Information")

## Purpose
Frequently asked questions regarding costs, the free prototype commitment, AI workflows, and post-launch support. Elevated to the portfolio gallery standard with an amethyst chamber (`--tint: #1d1626`), fine noise grain, `.rtop` brand header, and cursive italic summary titles.

## Files
- `faq.html`: HTML markup snippet.
- `faq.css`: Component styling.
- `index.html`: Fully self-contained runnable preview.

## Preview
Open `index.html` directly in your browser or run `npm run preview`.
