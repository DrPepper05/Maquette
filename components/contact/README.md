# Contact Component ("The Salon / Prototype Request")

## Purpose
The primary lead capture and prototype request area. Elevated to the portfolio gallery standard with an ember chamber (`--tint: #2b1216`), fine noise grain, `.rtop` brand header, frosted glass box, and refined form inputs with golden focus states.

## Files
- `contact.html`: HTML markup for `#contact`.
- `contact.css`: Form inputs, pill CTA, responsive stack, and status notification.
- `contact.js`: Form submission handler and feedback status toggle.
- `index.html`: Fully self-contained runnable preview.

## Preview
Open `index.html` directly in your browser or run `npm run preview`.
