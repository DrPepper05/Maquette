# Services Component ("The Studio / What We Build")

## Purpose
Presents the three studio delivery capabilities (Websites, Automations, Software) elevated to the portfolio presentation standard. Uses an ambient navy chamber (`--tint: #141d2e`), fine noise grain, `.rtop` brand header, and luminous gradient artwork cards with deep inset shadows.

## Files
- `services.html`: Pure HTML snippet for `#services`.
- `services.css`: Styling for the component.
- `index.html`: Fully self-contained runnable preview.

## Key Elements
- `.chamber`: Ambient tinted container with lighting pool and grain.
- `.piece`: Museum card art with multi-stop radial and linear gradients, monospace numbers (`01`, `02`, `03`), cursive italic titles (`Instrument Serif`), and sub-tags.
- `.rfoot` / `.sc-count`: Monospace tabular count `01 — 03`.

## Preview
Open `index.html` directly in your browser or run `npm run preview`.
