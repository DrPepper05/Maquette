# Header Component

## Purpose
The primary global navigation bar for Maquette. Features the cursive/italic editorial logo with golden glowing dot and a frosted glass capsule navigation menu with a high-contrast primary CTA.

## Files
- `header.html`: Standalone HTML markup snippet for the component.
- `header.css`: Component-specific CSS (fixed positioning, glassmorphism, mobile collapse).
- `index.html`: Self-contained runnable preview for testing and agent editing.

## Key Classes & Selectors
- `.logo`: Cursive `Instrument Serif` brand text with `<i></i>` glowing orb.
- `nav`: Pill capsule menu with `backdrop-filter: blur(12px)`.
- `nav a.cta`: Golden pill CTA linking to `#contact`.

## Preview
Open `index.html` in your browser or run `npm run preview`.
