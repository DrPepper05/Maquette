# Gallery Component ("The Collection")

## Purpose
An interactive 3D showcase gallery displaying featured case studies (`Northwind`, `Lumen`, `Forge`, `Verdant`, `Atlas`). Features real-time WebGL crumpled-paper shader deformation, SVG path ribbon trails, dynamic ambient room backdrops, and pointer/touch drag physics.

## Files
- `gallery.html`: HTML container structure (`#work`, `#showcase`, `#pieces`, `#crumple`).
- `gallery.css`: 3D perspective, viewport clamping, controls, metadata styling, and responsive layout.
- `gallery.js`: Physics engine, WebGL GLSL shaders, drag interactions, arrow key navigation, and project data array.
- `index.html`: Fully self-contained runnable preview.

## Key Controls
- Drag horizontally with mouse or finger to glide through projects.
- Click `←` or `→` buttons or use arrow keys.
- Horizontal trackpad swipe or shift + scroll wheel.

## Preview
Open `index.html` directly in your browser or run `npm run preview`.
