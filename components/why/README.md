# Why Component ("The Promise / Working With Us")

## Purpose
Presents the three client commitments (You own it, You see everything, No lock-in) elevated to the portfolio gallery standard. Wrapped in an emerald chamber (`--tint: #12211a`), fine noise grain, `.rtop` brand header, and luminous gradient artwork cards with deep inset shadows.

## Files
- `why.html`: Pure HTML snippet for `#why`.
- `why.css`: Styling for the component.
- `index.html`: Fully self-contained runnable preview.

## Preview
Open `index.html` directly in your browser or run `npm run preview`.
