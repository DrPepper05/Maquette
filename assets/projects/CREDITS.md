# Third-party assets used by the project landing pages

All assets below are CC0 / open-data and were downloaded once and stored locally.

## Northwind (`assets/projects/northwind/map/`)
- Map tiles: © OpenStreetMap contributors (ODbL). Fetched once from tile.openstreetmap.org (z15, 36 tiles).
- Driving routes: computed with the OSRM demo server (`routes.json`), data © OpenStreetMap contributors.

## Lumen (`assets/projects/lumen/`)
Poly Haven (https://polyhaven.com), CC0:
- Models: ceramic_vase_02, ceramic_vase_04, potted_plant_04
- Textures: marble_01 (limestone slabs, used for the floor), white_plaster_02 (pedestals)
- HDRI: photo_studio_loft_hall (lighting/reflections only)
The hero background `projects/lumen/bg.jpg` is a render of these assets plus procedural glass bottles.

## Verdant (`assets/projects/verdant/`, `projects/verdant/img/`)
Poly Haven (https://polyhaven.com), CC0:
- Models: food_apple_01, food_avocado_01, lemon, food_pears_asian_01, food_pomegranate_01
- HDRI: photo_studio_loft_hall (lighting only)
The product photos in `projects/verdant/img/` are renders of these scans (`projects/verdant/render.html`, hash = model name).
