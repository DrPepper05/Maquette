# Prompt pentru un site maker — concept pur, zero indicii de design

> De lipit în Lovable, v0, Bolt, Framer AI sau Figma Make.
> **Scopul:** să vedem ce direcție vizuală propune un model care nu a văzut niciuna dintre încercările noastre.
> Rulează-l în 2–3 unelte diferite — variația dintre ele e informația cea mai utilă.

---

## Promptul

```
Build a marketing website for a company called Maquette.

WHAT MAQUETTE IS
A software studio that builds custom software for companies: web
applications, websites, and business automations. Based in Romania,
working with Romanian small and mid-size companies and with
international clients.

Tagline: "First the model. Then the system."

THE CORE IDEA
Most software projects fail at the beginning, not during development —
because nobody wrote down clearly what needed to be built. Work starts
from a conversation and a rough estimate, and three months later the
unspoken assumptions surface.

So the first thing Maquette sells is not code. It is a fixed-price piece
of work called a Blueprint.

THE BLUEPRINT — 450 EUR, five working days
The client receives:
- A functional specification: what the system does, for whom, in what order
- A technical architecture: which components, which technologies, what
  integrates with what
- A clickable prototype
- A phased estimate, given as a range rather than a single number
- An execution plan and a list of risks

Two rules define the offer:
- The 450 EUR is deducted in full from the build project, if the build
  starts within 60 days
- If the client decides not to build with Maquette, the document is still
  theirs and they can take it to any other company

WHAT MAQUETTE BUILDS AFTER THE BLUEPRINT
1. Applications and websites — web applications, websites and catalogues,
   admin panels, client portals
2. Automations — connecting systems that do not talk to each other today
   (ERP, website, email, spreadsheets): automatic quotes and invoices,
   stock synchronisation, reporting that runs itself. Sold in hours saved,
   with a monthly maintenance subscription

Only the Blueprint price is shown on the site. For everything else:
"firm quote after a 30-minute call".

WHO THE CLIENT IS
Companies that have outgrown spreadsheets and group chats but do not have
an IT department yet. Furniture manufacturers, retailers, producers,
distributors. The person deciding is the owner or the commercial director.

WHAT MAQUETTE PROMISES
One price, one deadline, one person accountable from start to finish.
The code lives in the client's own repository from day one. Payment in
phases — never all at the end, never all up front. A written update every
Friday. Monitoring and a monthly report after launch.

PAGES
- Home
- Blueprint — the most important page on the site; this is where the sale
  happens. The Home page mainly exists to send people here.
- Services
- Work — no case studies are publishable yet; handle this honestly
- How we work — process, communication, what happens to the code and the
  accounts, payment terms, what happens if a deadline slips
- Contact — a short form

CONTENT RULES
- Never state how many people work at the company
- No team page, no client logos, no testimonials, no invented statistics —
  nothing that cannot be verified
- Plain language. No agency jargon.

Write all the copy yourself, based on the above.
```

## Ce am ținut deliberat în afara promptului

**Orice cuvânt care ar sugera un design.** Fără culori, fonturi, deschis/închis, layout, animații, imagini, și fără adjective ca „elegant", „modern", „minimal", „premium" — toate sunt instrucțiuni de design deghizate în descriere.

**Etimologia numelui.** „Maquette" = macheta pe care arhitectul o face înainte de clădire. E o poveste bună, dar e și fix capcana în care am căzut la prima încercare: modelul o traduce în vocabular de arhitectură și iese site de firmă de construcții. Am lăsat doar numele și taglineul.

Dacă vrei totuși să vezi ce iese cu metafora explicită, adaugi la final:
```
The name refers to the scale model an architect builds before construction.
```
Rulează ambele variante. Diferența dintre ele îți spune ceva.

**Zona Lab și Declutter.** Scot zgomot dintr-o explorare de design și oricum nu se publică încă.

**Bilingv RO/EN.** Complică rezultatul fără să adauge informație vizuală. Dacă vrei conținut în română, adaugi:
```
Write all copy in Romanian.
```

---

## Cum folosim rezultatul

Luăm **ideile**, nu codul. Ce ne interesează:
- Ce structură dă homepage-ului — ce pune primul, ce scoate
- Cum rezolvă problema paginii „Lucrări" fără studii de caz
- Ce face cu Blueprint-ul: pagină separată, calculator, tabel comparativ?
- Ce registru vizual alege singur, nefiind împins de nimeni

Dacă trei unelte diferite ajung la aceeași soluție pentru o secțiune, probabil e soluția corectă.
